# TeamVibe 구현 및 검증 기록

시작: 2026-09-21 17:28 KST. 목표 점검 마감: 2026-09-22 09:00 KST.

## 범위와 가정
- 로컬 전용 웹 앱. 외부 배포·자동 외부 전송·실제 업무 시스템 연결 없음.
- Vinext/React + 로컬 D1(SQLite). 여러 브라우저 세션이 같은 서버 데이터를 공유.
- 합성 사용자를 선택하는 데모 로그인 제공. 실제 기업 인증/SSO는 범위 밖.
- ChatGPT는 수동 복사/붙여넣기로 사용. 규칙 기반 초안은 AI 생성으로 표시하지 않음.
- PRD 합의, 스토리 의존성, 독립 작업 묶음, 결과 반입, 충돌 검사, 샌드박스 미리보기, 테스트/피드백을 실제 상태로 저장.
- 삭제는 복원 가능한 휴지통으로 구현. 원래 데이터의 물리 삭제 없음.
- 병렬 개발은 복수의 독립 작업을 동시에 진행 상태로 만들고 각 ChatGPT 세션에 작업 묶음을 전달. 자동 ChatGPT API 호출이나 완료 상태 시뮬레이션을 하지 않음.

## 예정된 검증
API 통합 흐름, 권한/충돌/입력검증, 브라우저 주요 사용자 여정, 데스크톱/모바일 렌더, 빌드, 실행 재시작 지속성. 실행하지 않은 것은 통과로 쓰지 않음.
